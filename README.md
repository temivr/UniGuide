# UniGuide

# About
UniGuide is a student engagement and attendance mobile application that helps students manage their timetable, attendance, announcements and campus map in one place.

# How to view UniGuide

Click on the Igor link to open UniGuide.

In Chrome you can access it through the menu:
- Click the three dots (⋮) in the top-right corner
- Select More tools → Developer tools
- Click the Toggle Device Toolbar icon (phone/tablet symbol)
- Choose an iPhone model

In Safari:
- Open Safari
- Click Safari → Settings → Advanced
- Enable Show features for web developers (or Show Develop menu)
- In the menu bar, click Develop → Enter Responsive Design Mode
- Choose an iPhone model
